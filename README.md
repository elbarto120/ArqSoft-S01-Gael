# Catálogo 2 - Sistema de Gestión

Este es un proyecto desarrollado en **ASP.NET Core** utilizando el patrón de diseño **MVC** (Modelo-Vista-Controlador). El objetivo del sistema es gestionar un catálogo de productos/servicios.

## 🚀 Características
* Gestión de usuarios con Identity.
* Arquitectura MVC para separar la lógica de negocio de la interfaz.
* Conexión a base de datos mediante Entity Framework.

## 🛠️ Tecnologías utilizadas
* **Lenguaje:** C#
* **Framework:** .NET 
* **Arquitectura:** MVC
* **Base de Datos:** SQL Server (u otra que estés usando)
